Claude Code CLI with an Anthropic API key

The Claude desktop app isn't enough. Install Claude Code CLI.

  1. Open {{ terminal }}, paste this and press {{ enter }}: {% if guide_platform == "windows" %}
    irm https://claude.ai/install.ps1 | iex
    {% else %}
    curl -fsSL https://claude.ai/install.sh | bash
    {% endif %}
  2. On console.anthropic.com, add credit under Billing.
  3. Under API keys, click Create Key and copy the key.
  4. Paste it in the Anthropic API key box.
  5. Click Save and test.
If something goes wrong

If Anthropic refuses the key, add credit or create a new key, then click Save and test again.

Claude Code CLI with your Claude subscription

You need a Claude Pro or Max plan. The Claude desktop app isn't enough. Install Claude Code CLI.

  1. Open {{ terminal }}, paste this and press {{ enter }}: {% if guide_platform == "windows" %}
    irm https://claude.ai/install.ps1 | iex
    {% else %}
    curl -fsSL https://claude.ai/install.sh | bash
    {% endif %}
  2. Open a new {{ terminal }} window, type claude and press {{ enter }}.
  3. Sign in with your Claude account in the browser window that opens.
  4. Type /exit and press {{ enter }}.
  5. Back here, click Use my Claude subscription.
If something goes wrong

Not on Pro or Max? Upgrade at claude.ai/upgrade.

If claude says "command not found", open a new {{ terminal }} window and try again there.
