Claude: your Claude subscription or an Anthropic API key

Claude works with either: your Claude subscription (Pro or Max) or an Anthropic API key.

With your Claude subscription

  1. You need a Claude account on a paid plan: Pro or Max. Buy or upgrade at claude.ai/upgrade.
  2. Install Claude in Terminal. On a Mac or Linux, open Terminal and paste: 
    curl -fsSL https://claude.ai/install.sh | bash
    On Windows, open PowerShell and paste: 
    irm https://claude.ai/install.ps1 | iex
    Press Return (Enter on Windows).
  3. Open a new Terminal (or PowerShell) window. The installer puts Claude in ~/.local/bin and only adds it for new windows, so in the same window claude gives "command not found". In the new window type claude and press Return.
  4. Claude asks how to sign in. Choose your Claude account with a subscription; a browser window opens; sign in. When Claude shows its prompt, type /exit and press Return.
  5. Back in Sidedoor, click Use my Claude subscription. Sidedoor checks the sign-in.

With an Anthropic API key

Anthropic then bills that key for everything Sidedoor does, so watch your usage.

  1. Install Claude as in step 2 above. Signing in is not needed for this way.
  2. Sign in at console.anthropic.com, add credit under Billing, then open API keys and click Create Key. Copy the key (it starts with sk-ant-); Anthropic shows it only once.
  3. In Sidedoor, click Use an Anthropic API key, paste the key and click Save. Sidedoor keeps the key on this computer and never shows it in full again.
  4. If Anthropic refuses the key, Sidedoor pauses its AI work and shows a banner until you save a key that works.

What is Terminal? On a Mac: Applications > Utilities > Terminal. What is PowerShell? On Windows: open the Start menu, type PowerShell and press Enter.
