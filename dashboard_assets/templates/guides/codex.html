Codex CLI with an OpenAI API key

The ChatGPT desktop app isn't enough. Install Codex CLI.

  1. Open {{ terminal }}, paste this and press {{ enter }}: {% if guide_platform == "windows" %}
    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
    {% else %}
    curl -fsSL https://chatgpt.com/codex/install.sh | sh
    {% endif %}
  2. On platform.openai.com, add credit under Billing.
  3. Under API keys, click Create new secret key and copy the key.
  4. Paste it in the OpenAI API key box.
  5. Click Save and test.
If something goes wrong

If OpenAI refuses the key, add credit or create a new key, then click Save and test again.
