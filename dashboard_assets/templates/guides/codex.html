Codex and a ChatGPT plan

  1. You need a ChatGPT account on a paid plan: Plus, Pro, Business, Edu or Enterprise. (Free and Go include Codex only in the desktop app, not the Terminal version Sidedoor uses.) Buy or upgrade at chatgpt.com/pricing.
  2. Install Codex. On a Mac or Linux, open Terminal and paste: 
    curl -fsSL https://chatgpt.com/codex/install.sh | sh
    On Windows, open PowerShell and paste: 
    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
    Press Return (Enter on Windows). The same command updates Codex later.
  3. At the end the installer asks "Start Codex now?". Type y and press Return (pressing Return alone means No). That starts Codex and its sign-in. Choose Sign in with ChatGPT; a browser window opens; sign in with your ChatGPT account. If you answered No, or whenever you later type a codex command, open a new Terminal (or PowerShell) window first: on a Mac or Linux the installer puts Codex in ~/.local/bin and only adds it for new windows, so in the same window codex gives "command not found". In the new window type codex and press Return.
  4. Choose Sign in with ChatGPT. Sidedoor needs this sign-in, and it means you never handle an API key. If Codex is already signed in with an API key, switch it (in a new Terminal window):
    1. Type codex logout and press Return.
    2. Type codex login and press Return. A browser window opens; sign in with your ChatGPT account.
  5. Back in Sidedoor, click Check in step 6.

What is Terminal? On a Mac: Applications > Utilities > Terminal. What is PowerShell? On Windows: open the Start menu, type PowerShell and press Enter.
