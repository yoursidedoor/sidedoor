Codex and a ChatGPT plan

Codex works with either: Sign in with ChatGPT (the default) or an OpenAI API key (optional). If one stops working, Sidedoor uses the other.

  1. You need a ChatGPT account on a paid plan: Plus, Pro, Business, Edu or Enterprise. (Free and Go include Codex only in the desktop app, not the Terminal version Sidedoor uses.) Buy or upgrade at chatgpt.com/pricing.
  2. Install Codex. On a Mac or Linux, open Terminal and paste: 
    curl -fsSL https://chatgpt.com/codex/install.sh | sh
    On Windows, open PowerShell and paste: 
    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
    Press Return (Enter on Windows). The same command updates Codex later.
  3. At the end the installer asks "Start Codex now?". Type y and press Return (pressing Return alone means No). That starts Codex and its sign-in. Choose Sign in with ChatGPT; a browser window opens; sign in with your ChatGPT account. If you answered No, or whenever you later type a codex command, open a new Terminal (or PowerShell) window first: on a Mac or Linux the installer puts Codex in ~/.local/bin and only adds it for new windows, so in the same window codex gives "command not found". In the new window type codex and press Return.
  4. Choose Sign in with ChatGPT. This is the sign-in Sidedoor uses unless you choose an OpenAI API key (below). If Codex is already signed in with an API key, switch it (in a new Terminal window):
    1. Type codex logout and press Return.
    2. Type codex login and press Return. A browser window opens; sign in with your ChatGPT account.
  5. Back in Sidedoor, click Check in step 6.

Or: Codex with an OpenAI API key

Optional. Codex can use an OpenAI API key; OpenAI then bills that key for everything Sidedoor does, so watch your usage. You can keep Codex signed in with ChatGPT as well: if the key stops working, Sidedoor uses your ChatGPT sign-in.

  1. Install Codex as in step 2 above. Signing Codex in with ChatGPT is optional, as a fallback.
  2. Sign in at platform.openai.com, add credit under Billing, then open API keys and click Create new secret key. Copy the key (it starts with sk-); OpenAI shows it only once.
  3. In Sidedoor's step 6, click Use an OpenAI API key, paste the key and click Save and test. The test reads which models your key can use and makes one tiny call (a tiny amount of credit). Sidedoor keeps the key on this computer and never shows it in full again.
  4. If your key runs out of credit or OpenAI refuses it, Sidedoor uses your ChatGPT sign-in and shows a banner; once a key passes its test again, Sidedoor goes back to the key. With no ChatGPT sign-in, Sidedoor waits (no work is lost) until you add credit or replace the key. You can switch to Sign in with ChatGPT at any time; the key stays saved until you remove it.

What is Terminal? On a Mac: Applications > Utilities > Terminal. What is PowerShell? On Windows: open the Start menu, type PowerShell and press Enter.
