Create your OpenRouter key

  1. On openrouter.ai, sign in or create an account.
  2. On the Credits page, add a few dollars of credits.
  3. On the Keys page, create a key named Sidedoor and copy it.
  4. Paste it in the OpenRouter key box.
  5. Click Save and test.
If something goes wrong

If the test says there are no credits, add credits on the Credits page, then click Save and test again.

OpenRouter shows a key only once. If you lost it, create a new one on the Keys page.
